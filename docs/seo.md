# Search and sharing

The canonical origin defaults to `https://lokeshdhakar.in`. If the portfolio is deployed at a different canonical domain, set `NEXT_PUBLIC_SITE_URL` to that origin before building and redeploying. The same setting is used for canonicals, Open Graph URLs, structured data, robots, and the sitemap. Configure host-level redirects separately so alternate domains redirect to the preferred domain.

The sitemap is generated from the case-study data and `lib/field-notes.json`; new notes appear automatically after a build. The site does not invent publication or modification dates. Icon files are under `app/`, and the share image is generated by `app/opengraph-image.jsx`.

After deployment, check that `/robots.txt`, `/sitemap.xml`, `/favicon.ico`, and `/opengraph-image` load on the public domain, and inspect representative pages with Google Search Console's URL Inspection and Rich Results Test. Submit the sitemap in Search Console. Indexing, search snippets, and rich results remain at each search engine's discretion.
